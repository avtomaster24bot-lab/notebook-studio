# Notebook Studio — браузерный аналог NotebookLM + завод рилсов

**Открыть:** https://avtomaster24bot-lab.github.io/notebook-studio/

Работает прямо в браузере (компьютер и телефон), без установки. Данные блокнотов хранятся в браузере (IndexedDB).

## Что умеет

| Раздел | Что делает | Чем генерируется |
|---|---|---|
| **Источники** | PDF, DOCX, TXT/MD/HTML/CSV, ссылки на статьи и PDF, вставка текста, поиск статьи в Википедии | pdf.js, mammoth.js, серверный прокси для ссылок |
| **Чат с источниками** | Ответы только по источникам со ссылками-цитатами `[1]` → клик показывает фрагмент | поиск BM25 по фрагментам + LLM |
| **Краткий обзор, Учебное пособие, FAQ, Брифинг, Хронология** | Документы по источникам (или по теме) | LLM |
| **Аудиопересказ** | Подкаст на два голоса (Анна и Максим) 3–5 минут, WAV | LLM + голоса Microsoft Neural |
| **Пост / текст** | Instagram, Telegram, статья, сценарий YouTube, рассылка, карусель, лендинг | LLM |
| **Картинки** | Нарисовать ИИ (9:16, 4:5, 1:1, 16:9, 5 стилей) или найти сток-фото | Agnes Image / Pollinations FLUX; Pexels / Pixabay / Wikimedia Commons |
| **Музыка** | Фоновый трек без авторских прав (6 настроений) или свой mp3 | синтез в браузере (Web Audio) |
| **🎬 Рилс 9:16** | Тема → сценарий (редактируется) → озвучка → картинки → музыка → анимированные субтитры по словам → **MP4 1080×1920** | всё выше + рендер в браузере (WebCodecs H.264) |

Рилс: хук-заголовок, плашки «01 …» для каждого пункта, эффект Ken Burns, плавные переходы, субтитры с подсветкой текущего слова (тайминги от синтезатора речи), прогресс-бар, подпись @ника, финальный призыв, подпись к посту с хэштегами и авторами фото.

## Сервисы и ключи

Без ключей всё работает на бесплатных сервисах. Ключи повышают качество:

| Сервис | Для чего | Куда вписать |
|---|---|---|
| **Agnes AI** (как в «контент-заводе») | лучший текст `agnes-2.5-flash` и картинки `agnes-image-2.1-flash` | секрет функции Supabase `AGNES_API_KEY` **или** ⚙ Настройки на сайте |
| **Pollinations** (enter.pollinations.ai) | сильные модели и картинки в полном разрешении | `POLLINATIONS_API_KEY` или ⚙ Настройки |
| **Pexels** (pexels.com/api) | качественные сток-фото | `PEXELS_API_KEY` или ⚙ Настройки |
| **Pixabay** | сток-фото | `PIXABAY_API_KEY` |
| Microsoft Edge Neural TTS | озвучка (Светлана, Андрей и др.) | ключ не нужен |

Ключи из ⚙ Настроек хранятся только в браузере пользователя и передаются на свой сервер по HTTPS; в коде сайта ключей нет.

Добавить секрет на сервер: Supabase → проект **VEZU** → Edge Functions → Secrets → `AGNES_API_KEY` (или командой `supabase secrets set AGNES_API_KEY=... --project-ref sfgrwquitlnzlkyzashb`).

## Устройство

```
index.html, css/, js/          — сайт (GitHub Pages, без сборки)
  js/app.js                    — интерфейс: блокноты, источники, чат, студия
  js/rag.js                    — нарезка и поиск по источникам (BM25)
  js/reel.js                   — завод рилсов: сценарий → ассеты → рендер MP4
  js/music.js                  — генератор музыки
supabase/functions/notebook-studio/  — сервер (Supabase Edge Function)
  /llm  /image  /tts  /stock  /proxy  /health
```

Деплой функции: `supabase functions deploy notebook-studio --project-ref sfgrwquitlnzlkyzashb --no-verify-jwt`.
Сервер принимает запросы только с `https://avtomaster24bot-lab.github.io` и localhost (переменная `ALLOWED_ORIGINS` — дополнительные сайты).

## Ограничения

- Бесплатный режим Pollinations ограничен по частоте: при частых запросах картинки идут медленнее, а при сбое берётся сток-фото. С ключом Agnes/Pollinations — стабильно и качественнее.
- В Chrome на Windows/Mac звук в MP4 — AAC; в Chrome на Linux — Opus (Instagram может перекодировать).
- Видеоклипы в рилсе пока не поддерживаются — только фото/картинки.
